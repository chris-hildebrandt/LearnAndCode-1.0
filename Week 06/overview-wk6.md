# **Week 6: GIT - Advanced Techniques and Best Practices**

This week, we will introduce version control using Git, aligning with In Time Tec's emphasis on collaboration, communication, and continuous integration and deployment.

## **Learning Objectives**

By the end of this week, you should be able to:

- Deepen your understanding of Git’s advanced features and commands
- Implement advanced branching strategies and workflows
- Resolve complex merge conflicts and understand rebase vs. merge
- Integrate Git with continuous integration and deployment pipelines

## **Weekly Assignment**

1. Explore advanced Git commands and features (e.g., rebase, cherry-pick, stash).
2. Complete the advanced portion of the Git tutorial: **[https://learngitbranching.js.org/?locale=en_US](https://learngitbranching.js.org/?locale=en_US)**
3. Resolve a complex merge conflict scenario provided by the instructor?

## **Submission Guidelines**

- Submit a README file to the submissions folder for your cohort with a description of your experiences with Git, and an overview of the branching strategy used in your project.
- Discuss any challenges or insights you gained from completing the Git tutorial.
- Open a PR with your name and week number, and your instructor will review the PR and provide comments. Feel free to engage with other students' PRs and generate a discussion. Example: jdoe-week-14.

## **Discussion Topics**

During your weekly meeting with your mentor and peers, be prepared to discuss the following topics:

- Share your experiences with advanced Git commands and features.
- Discuss different branching strategies (e.g., Git Flow, GitHub Flow) and their pros and cons.
- Share any complex merge conflicts you’ve encountered and how you resolved them.
- Discuss how Git integrates with CI/CD pipelines and the benefits it brings to your project.
