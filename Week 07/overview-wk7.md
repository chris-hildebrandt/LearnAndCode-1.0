
# **Week 7: Code Review & Technical Excellence**

This week, we are focusing on the importance of code review in creating high-quality software, and how it aligns with In Time Tec's emphasis on technical excellence. We will also explore the relationship between code review and the Quality Manifesto's emphasis on clear technical documentation.

## **Learning Objectives**

By the end of this week, you should be able to:

- Understand the importance of code review in creating high-quality software
- Apply best practices for code review and feedback implementation
- Conduct a code review with your mentor and implement the feedback
- Discuss the relationship between code review and the Quality Manifesto's emphasis on clear technical documentation

## **Weekly Assignment**

1. Conduct a code review of your project with your mentor and implement the feedback.
2. Document the feedback you received and the changes you made in a brief report.
3. Be prepared to share the feedback you received and the changes you made with your peers during your weekly meeting.

## **Submission Guidelines**

- Submit a README file to the submissions folder for your cohort with an example of the feedback you received and the changes you made. Open a PR with your name and week number, your instructor will look at the PR and add comments. Feel free to look at other students' PRs and generate a discussion. Example - dallen-pyrah-week-4

## **Discussion Topics**

During your weekly meeting with your mentor and peers, be prepared to discuss the following topics:

- Share examples of the feedback you received during your code review and the changes you made to your project.
- Discuss the impact of your changes on code quality and maintainability.
- Share challenges you faced while implementing the feedback and how you overcame them.
- Discuss the relationship between code review and the Quality Manifesto's emphasis on clear technical documentation.
