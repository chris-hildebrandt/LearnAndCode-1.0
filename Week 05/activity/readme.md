## **Acitivty set-up**

   - Before this weeks Learn And Code Cohort meeting, create a branch [week05-activity-mm-dd] for everyone to use

## **During Cohort Meeting**

    - Create a new file [cohort-{x}.md] and ask a simple question within the file
        Example: "What is your most commonly used git command?"
    - Commit the file and Push the branch, ask everyone to checkout the branch, answer the question, commit and push their changes.
    - Help resolve conflicts as needed.
