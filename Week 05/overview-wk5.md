# **Week 5: GIT - Introduction to Version Control**

This week, we will introduce version control using Git, aligning with In Time Tec's emphasis on collaboration, communication, and continuous integration and deployment.

## **Table of Contents**

- **[Learning Objectives](#learning-objectives)**
- **[Resources](#resources)**
- **[Weekly Assignment](#weekly-assignment)**
- **[Submission Guidelines](#submission-guidelines)**
- **[Discussion Topics](#discussion-topics)**

## **Learning Objectives**

By the end of this week, you should be able to:

- Understand the fundamentals of version control using Git
- Apply best practices for using Git in your project
- Perform basic version control tasks, such as branching, merging, and conflict resolution
- Discuss the relationship between Git, collaboration, communication, and In Time Tec's commitment to continuous integration and deployment

## **Weekly Assignment**

1. Analyze how Git is being used in your project, and perform basic version control tasks such as branching, merging, and conflict resolution.
2. Complete the basic section of the following Git tutorial: **[https://learngitbranching.js.org/?locale=en_US](https://learngitbranching.js.org/?locale=en_US)**
3. Review your project's branching strategy and your experiences with the Git tutorial during your weekly meeting with your mentor.

## **Submission Guidelines**

- Submit a README file to the submissions folder for your cohort with a description of your experiences with Git, and an overview of the branching strategy used in your project.
- Discuss any challenges or insights you gained from completing the Git tutorial.
- Open a PR with your name and week number, and your instructor will review the PR and provide comments. Feel free to engage with other students' PRs and generate a discussion. Example: jdoe-week-14.

## **Discussion Topics**

During your weekly meeting with your mentor and peers, be prepared to discuss the following topics:

- Share your experiences with Git and the branching strategy used in your project.
- Discuss the impact of using Git on collaboration, communication, and continuous integration and deployment.
- Share challenges you faced while learning and using Git and how you overcame them.
- Discuss the relationship between Git, collaboration, communication, and In Time Tec's commitment to continuous integration and deployment.
