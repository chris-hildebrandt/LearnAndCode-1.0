# Learn & Code Curriculum for In Time Tec

Welcome to Learn & Code, a comprehensive internal course designed to help first-year engineers at In Time Tec develop the necessary skills and knowledge to advance in their careers. This curriculum revolves around Clean Code principles by Bob Martin and incorporates In Time Tec's Quality Manifesto. By the end of this 27-week course, you will have a strong foundation in various development concepts and practices, with an emphasis on clean coding principles.

## Course Structure

The curriculum spans 27 weeks, with each topic building upon previous concepts:

**Foundational Engineering Practices** 
- **[Week 1: Introduction to Quality Manifesto & Clean Code Principles](Week%2001/overview.md)** - Learn about In Time Tec's Quality Manifesto and foundational Clean Code concepts
- **[Week 2: Meaningful Names](Week%2002/overview.md)** - Understand the importance of clear, descriptive naming conventions
- **[Week 3: Foundational AI Development/Prompt Engineering](Week%2003/overview.md)** - Master AI tools and prompt engineering for enhanced development
- **[Week 4: Functions](Week%2004/overview.md)** - Learn to write clean, efficient, and maintainable functions
- **[Week 5: GIT - Introduction](Week%2005/overview.md)** - Master basic version control concepts and practices
- **[Week 6: GIT - Advanced Techniques](Week%2006/overview.md)** - Explore advanced Git workflows and collaboration
- **[Week 7: Code Review](Week%2007/overview.md)** - Learn effective code review techniques and best practices

**Code Structure & System Design** 
- **[Week 8: Classes & Systems Part 1](Week%2008/overview.md)** - Understand object-oriented design principles
- **[Week 9: Classes & Systems Part 2](Week%2009/overview.md)** - Master advanced class design and system architecture
- **[Week 10: Objects & Data Structures Part 1](Week%2010/overview.md)** - Learn about data encapsulation and abstraction
- **[Week 11: Objects & Data Structures Part 2](Week%2011/overview.md)** - Explore advanced data structure concepts
- **[Week 12: Error Handling Part 1](Week%2012/overview.md)** - Master exception handling fundamentals
- **[Week 13: Error Handling Part 2](Week%2013/overview.md)** - Learn advanced error management techniques
- **[Week 14: Boundaries & Integrations](Week%2014/overview.md)** - Understand system boundaries and third-party integrations

**SOLID Engineering Principles** 
- **[Week 15: Single Responsibility](Week%2015/overview.md)** - Learn to create focused, maintainable classes
- **[Week 16: Open/Closed](Week%2016/overview.md)** - Master extensible software design
- **[Week 17: Liskov Substitution](Week%2017/overview.md)** - Understand proper inheritance and polymorphism
- **[Week 18: Interface Segregation](Week%2018/overview.md)** - Learn to design focused interfaces
- **[Week 19: Dependency Inversion](Week%2019/overview.md)** - Master dependency management and inversion of control

**Production-Grade Development** 
- **[Week 20: API Design & Integration](Week%2020/overview.md)** - Learn RESTful API design principles
- **[Week 21: Unit Tests & Test-Driven Development](Week%2021/overview.md)** - Master automated testing practices
- **[Week 22: Design Patterns Part 1](Week%2022/overview.md)** - Understand common software design patterns
- **[Week 23: Design Patterns Part 2](Week%2023/overview.md)** - Apply advanced design patterns
- **[Week 24: Event-Driven Architecture](Week%2024/overview.md)** - Learn modern architectural patterns
- **[Week 25: Concurrency & Performance](Week%2025/overview.md)** - Master parallel programming concepts
- **[Week 26: Refactoring & Code Smells](Week%2026/overview.md)** - Identify and fix problematic code
- **[Week 27: Documentation & Communication](Week%2027/overview.md)** - Learn technical writing and team communication

## Learning Objectives

By the end of this course, participants will be able to:
- Apply Clean Code principles and Quality Manifesto in their work
- Develop customer-centric solutions using clean coding practices
- Implement secure software development practices
- Master CI/CD for automated builds, integration, and testing
- Perform effective code reviews following SOLID principles
- Work with Git version control and branching strategies
- Communicate clearly in team settings
- Create and maintain technical documentation
- Identify and document non-functional requirements
- Practice refactoring to prevent code deterioration
- Implement software security best practices

## Program Components

**Project Selection**
Each participant will choose a current or recent project as a case study throughout the course. This project will serve as a practical application ground for the concepts learned during the program.
