# **Week 26: Code Smells & Heuristics**

This week, we will focus on refactoring techniques and how to identify code smells, connecting these concepts to In Time Tec's commitment to continuous improvement and the Quality Manifesto's emphasis on technical excellence.

## **Learning Objectives**

By the end of this week, you should be able to:

- Understand the concept of code smells and heuristics
- Identify code smells in your project
- Apply refactoring techniques to address code smells
- Discuss the benefits of addressing code smells in the context of continuous improvement and technical excellence

## **Weekly Assignment**

Identify code smells in your project that you would like to present on and be prepared to talk for 3-5 minutes about what type of code smell it is that you identified, what you would do to change it, why you might not want to change it but it is still a code smell, or anything else you would like to share about it. The goal here is to work on identifying code smells in our projects and then sharing those findings with each other as a group.
