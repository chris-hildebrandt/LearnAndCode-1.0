# **Week 20: API Design & Integration**

This week focuses on helping junior developers understand REST API fundamentals and best practices, preparing them to work effectively with APIs in real projects.

## **Learning Objectives**

By the end of this week, you should be able to:

- Understand fundamental REST API principles and conventions
- Identify common HTTP methods and status codes
- Read and understand API documentation
- Recognize REST API best practices and common pitfalls
- Work with existing APIs effectively

## **Weekly Assignment**

1. Review an existing public API documentation (choose from GitHub, Twitter, or Stripe)
2. Document the following in your submission:
   - Three examples of well-designed endpoints
   - Common patterns in the API's error handling
   - How the API handles authentication
   - One thing you found interesting about the API design

## **Submission Guidelines**

- Submit a README file to the submissions folder for your cohort with your API analysis
- Open a PR with your name and week number (Example: dallen-pyrah-week-19)
- Your instructor will review the PR and add comments
- Review other students' PRs to learn from their analyses

## **Discussion Topics**

During your weekly meeting, be prepared to discuss:

- Common REST API naming conventions you observed
- Different authentication methods used in APIs
- How APIs handle versioning
- Best practices for error handling
- The importance of clear API documentation
